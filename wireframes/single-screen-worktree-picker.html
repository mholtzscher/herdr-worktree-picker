Herdr Worktree Picker

Review question: Can branch selection, direct opening, and new-branch naming work on one persistent surface without losing context or safety?

Interactive popup

Click rows or use the search box and keyboard shortcuts.

Worktree branch ~/code/herdr-worktree-picker

What changed

  1. No action screen.
    Enter opens the selected branch immediately.
  2. One input, two explicit roles.
    Ctrl-N locks the selection as the base and changes Search into New branch from…
  3. Safety is contextual.
    Only conflicts, invalid names, and checked-out branches interrupt the fast path.
  4. No-results text is reusable.
    A valid unmatched query can become a branch from HEAD without retyping.
Primary job
Find a branch and open its worktree quickly.
Fast path
Search → select → Enter.
Secondary path
Select base → Ctrl-N → keep or replace draft → Enter.

1 · OpenShortcut opens popup in the current repository.
